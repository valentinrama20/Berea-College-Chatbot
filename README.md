# Berea-College-Chatbot

## Description/Motivation
This project is a front-end application which ties with what I want to do in the future. Through this project, I want to create a ChatBot that can answer questions about Berea College. The ChatBot will be able to answer questions about the college's history, programs, admissions, and other relevant information for people who want to apply to Berea College. The goal is to provide a user-friendly interface for prospective students and current students to get quick answers. The project itself is going to be simple with the use of HTML, CSS, and JavaScript, and no framework.

## Built With
- Visual Studio Code  
- HTML  
- CSS (**dark navy theme**, responsive design)  
- JavaScript (**keyword-based Q&A**, **drawer menu**, **typing effect**, **small-talk handling**)

## Scope
The chatbot will answer questions using a small keyword list inside the code.  
It will show answers in chat bubbles, **quick-ask buttons** (inside a slide-in **drawer menu**), **typing dots** for realism, and **follow-up chips** to guide users.  
It also has a **“New chat”** button to clear and restart conversations.  

## Vision
The vision is to make a simple chatbot that helps people get Berea College info fast without needing to browse multiple pages. At the end of the semester, it will be a working one-page site but not deployed. Future updates may include APIs, React, or audio.
